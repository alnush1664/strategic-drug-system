# مرز سیستم و محیط آن

در این بخش، مرزهای سامانه مدیریت و پایش داروهای استراتژیک مشخص می‌شود.  
منظور از مرز سیستم این است که چه بخش‌هایی جزو خود سامانه هستند و چه بخش‌هایی خارج از سامانه قرار دارند اما با آن در ارتباط هستند.
## محیط سیستم
محیط سیستم شامل تمامی کاربران، نهادها و سامانه‌هایی است که به نحوی با سامانه مدیریت و پایش داروهای استراتژیک در ارتباط هستند.  
این محیط می‌تواند شامل سازمان غذا و دارو، انبارهای دارویی، مراکز درمانی و نهادهای تصمیم‌گیر باشد.

## جمع‌بندی
تعیین مرز سیستم باعث می‌شود محدوده عملکرد سامانه به صورت دقیق مشخص شود و تعامل آن با کاربران و سامانه‌های خارجی بهتر قابل تحلیل باشد.
