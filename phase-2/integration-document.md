# Integration Document (سند یکپارچگی نمودارها)

این سند نحوه ارتباط و یکپارچگی بین نمودارهای مختلف فاز ۲ را تشریح می‌کند.

## ۱. ارتباط نمودارها
- **ارتباط Use Case با Domain Class:** توضیح داده شود که کدام موجودیت‌ها در کلاس دامنه، پشتیبانی‌کننده کدام مورد کاربرد (Use Case) هستند.
- **ارتباط Domain Class با Sequence/Activity:** نحوه استفاده از کلاس‌های دامنه در طول اجرای سناریوهای بحرانی و فرآیندهای سیستم.
- **ارتباط State با سایر نمودارها:** نمایش اینکه تغییر حالت موجودیت‌های کلیدی در نمودار کلاس چگونه در فرآیندها (Activity) تاثیر می‌گذارد.

## ۲. بررسی سازگاری (Consistency Check)
- تأیید می‌کنیم که نام کلاس‌ها، متدها و نقش‌ها در تمامی نمودارها یکسان است.

## ۳. نقشه کلی (Mind Map Reference)
- این سند با دیدگاه کلی ارائه شده در Mind Map تطابق کامل دارد.
