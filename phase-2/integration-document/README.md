# سند یکپارچگی نمودارها (Integration Document)

این پوشه شامل مستندات مربوط به هماهنگی، یکپارچگی و ارتباط منطقی بین تمامی نمودارهای مدل‌سازی شده در فاز ۲ است.

## محتویات این پوشه:
- **README.md**: راهنمای کلی و توضیحات هماهنگی نمودارها.
- **سند اصلی**: (می‌توانید فایل Word یا PDF نهایی را پس از تکمیل در این پوشه آپلود کنید).

## موارد مورد بررسی در یکپارچگی:
1. ارتباط بین نقش‌ها (Actors) در نمودار Use Case با کلاس‌های کاربری.
2. همخوانی جریان‌های کاری در نمودار Activity با توالی پیام‌ها در Sequence Diagram.
3. تطابق وضعیت‌های موجودیت‌ها در State Diagram با متدهای تعریف شده در Domain Class Diagram.
