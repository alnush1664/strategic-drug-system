# Activity Diagram

این پوشه برای نگهداری نمودارهای فعالیت (Activity Diagrams) مربوط به فرآیندهای پروژه سامانه مدیریت و پایش داروهای استراتژیک استفاده می‌شود.

## توضیحات
- در این بخش، جریان کار (Workflow) و توالی فعالیت‌های اصلی سیستم مدل‌سازی می‌شود.
- نمودارهای این پوشه باید فرآیندهای پیچیده و مراحل اجرایی سیستم را به صورت گام‌به‌گام نمایش دهند.
