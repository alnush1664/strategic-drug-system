# State Diagram

این پوشه برای نگهداری نمودارهای وضعیت (State Diagrams) سیستم و اشیای اصلی پروژه استفاده می‌شود.

## توضیحات
- نمودارهای این بخش تغییر حالات (States) موجودیت‌ها را در طول چرخه عمرشان نمایش می‌دهند.
- این نمودارها برای مدل‌سازی حالت‌های مختلف داروها، سفارش‌ها، یا سایر موجودیت‌های کلیدی پروژه که دارای چرخه‌های حیات مشخصی هستند، بسیار مفیدند.
